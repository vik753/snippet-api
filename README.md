# Учебный проект: SnippetAPI (NodeJS + Express + PostgreSQL)

RESTful сервис для сохранения полезных кусков кода, ссылок и заметок.

## Сущности базы данных:

1. `snippets` (фрагменты кода или ссылки)
2. `tags` (теги для фильтрации)
3. `snippet_tags` (связующая таблица для отношения "многие-ко-многим")
4. `users` (пользователи сервиса)

## Архитектура эндпоинтов:

| Метод    | Маршрут              | Описание                                                         |
| :------- | :------------------- | :--------------------------------------------------------------- |
| `GET`    | `/api/snippets`      | Получить список всех сниппетов (с поддержкой фильтрации по тегу) |
| `GET`    | `/api/snippets/:id`  | Получить конкретный сниппет                                      |
| `POST`   | `/api/snippets`      | Создать новый сниппет                                            |
| `PUT`    | `/api/snippets/:id`  | Обновить существующий сниппет                                    |
| `DELETE` | `/api/snippets/:id`  | Удалить сниппет                                                  |
| `POST`   | `/api/auth/register` | Регистрация пользователя                                         |
| `POST`   | `/api/auth/login`    | Авторизация и выдача JWT в куки                                  |
| `POST`   | `/api/auth/logout`   | Выход и очистка куки                                             |
| `GET`    | `/api/auth/me`       | Получение профиля текущего пользователя                          |
